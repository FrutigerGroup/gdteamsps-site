# GDTEAMSPS (GDPS+ Teams)

This repository contains two different static website designs for the GDTEAMSPS Geometry Dash Private Server project.

## Folders

- `gdteamsps-classic/` — retro/styled multi-page website
- `gdteamsps-modern/` — modern landing page and rules page
- `index.html` — landing page that links to both sites

## Live website

GitHub Pages can be enabled from the repository settings and serves the root `index.html` automatically.

## Files

Open any of these in a browser:
- `index.html`
- `gdteamsps-classic/index.html`
- `gdteamsps-modern/index.html`

## Notes

The content is static and easy to customize. Replace placeholder join links and server information as needed.
