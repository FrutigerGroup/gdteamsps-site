Welcome to GDTEAMSPS

A Geometry Dash Private Server themed around teams, community events, custom levels, fair play, and an active player base. This repository includes two different website styles, so you can choose the one that best fits your server identity.

Classic Design

A simple retro-styled website with a clean home page and dedicated rules page. Ideal if you want a classic, minimal GDPS look that feels familiar and easy to read.

Modern Design

A more modern layout with a responsive landing page, updated styling, and a clean rulebook. Better for a more polished server brand or a newer community look.
